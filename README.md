# untitled1

Icecream-Flutter 🍦
A cross-platform software application for an ice cream selling app, built to run across Android, Windows, and MacOS.
Features
Cross-platform support (Android, Windows, MacOS)
Browse ice cream menu and place orders
Cloud-based data storage and sync
Tech Stack
Framework: Flutter
Language: Dart
Backend: Firebase
IDE: Android Studio
Project Details
Duration: 1 week
Team Size: 1 (solo project)
